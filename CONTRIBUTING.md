# Contributing to telarch-benchmarks

Thank you for contributing to the Telarch benchmark suite.

## Rules
1. All benchmarks must run in one command via `make bench`.
2. All figures in `claims.json` must be reproducible within their stated ranges.
3. Zero hostnames or personal emails in benchmark reports or code.
4. Lints must pass with zero warnings (`make check`).
5. Contributions are licensed under the MIT License.
